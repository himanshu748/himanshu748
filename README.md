## Selected work

**AI agents and developer infrastructure**

- **[OmniDev](https://github.com/himanshu748/omnidev)**: Native macOS assistant with cited local file and screenshot search, scoped code edits, tests, MCP tools, and optional local Ollama inference. [Case study](https://himanshu748.com/builds/omnidev/) · [Architecture](https://github.com/himanshu748/omnidev/blob/main/docs/ARCHITECTURE.md)
- **[ContextFirewall](https://github.com/himanshu748/ContextFirewall)**: Memory trust checks that flag stale facts, contradictions, secrets, and unsupported claims before an agent uses recalled context. [Case study](https://himanshu748.com/builds/contextfirewall/)
- **[Graft](https://github.com/himanshu748/graft-webmcp)**: Review semantic HTML evidence, generate WebMCP tool contracts, and verify deployed adapters. [Workbench](https://graft-webmcp.vercel.app) · [Case study](https://himanshu748.com/builds/graft/)
- **[VOX](https://github.com/himanshu748/vox-zero-touch-os)**: Voice-to-plan support workflow with approvals, persisted results, and spoken briefings. Uses fictional tickets and simulated sends for the demo. [Case study](https://himanshu748.com/builds/vox/)
