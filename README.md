## Selected builds

### [Flatpack](https://github.com/himanshu748/flatpack)
Turns a narrated how-to video into a printable, illustrated instruction sheet. Review each step, choose a better frame and redraw the plate before printing. A local prototype using Livepeer Agent and ffmpeg.

[Watch the demo](https://youtu.be/8NnJxZxHLEI) · [2nd place, Agent Builder track, Livepeer Agent Hackathon 2026](https://atumera.com/hackathon)

### [₹800](https://github.com/himanshu748/rs800)
A heat-aware work-planning prototype for outdoor workers in India. Uses OR-Tools CP-SAT to schedule jobs, travel and rest around configured heat rules, with English and Hindi interfaces. Shows the income shortfall when the constraints cannot accommodate every job.

[Watch the demo](https://www.youtube.com/watch?v=xtvfS-8Q3ro) · Python / FastAPI / Next.js / AWS

### [otel-swarm](https://github.com/himanshu748/otel-swarm)
OpenTelemetry instrumentation for multi-agent workflows, with a runnable example, SigNoz dashboards and alerts. Makes model fallbacks and review events visible in a trace.

[Read the technical guide](https://dev.to/himanshu_748/tracing-a-multi-agent-llm-system-otel-swarm-and-a-signoz-dashboard-pack-4m85)

### [ContextFirewall](https://github.com/himanshu748/ContextFirewall)
An MCP-based prototype for checking agent memory for stale information, contradictions, secrets and missing evidence. Built with Cognee, FastAPI and Next.js.
